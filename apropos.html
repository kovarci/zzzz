Every morning Lotent gathers the talks, lectures and seminars open to the public in Paris. This page shows how, with today’s numbers: everything displayed here is measured at each update, nothing is typed by hand.

Un piège réel : le Collège de France répondait du binaire illisible, parce que le robot annonçait savoir lire le brotli. Une ligne retirée a ramené cinq sources à la vie.

A real trap: the Collège de France answered with unreadable binary because the robot claimed it could read brotli. One line removed brought five sources back to life.

CDF_HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; …) Chrome/124.0.0.0 Safari/537.36",
    "Accept-Language": "fr-FR,fr;q=0.9,en;q=0.8",
    # Pas de « br » : requests ne décode pas le brotli sans le paquet brotli,
    # et le site répondait alors du binaire illisible (0 carte lue)
    "Accept-Encoding": "gzip, deflate",
}

Un robot, chaque matinOne robot, every morning

GitHub Actions lance le scraper Python chaque jour à 4 h UTC. requests et BeautifulSoup lisent les pages ; Playwright pilote un vrai Chromium pour celles qui se construisent en JavaScript.

GitHub Actions runs the Python scraper every day at 4 am UTC. requests and BeautifulSoup read the pages; Playwright drives a real Chromium for the ones built in JavaScript.

Les sources qui bloquent les robots des data-centers (Collège de France, Louvre, Muséum, Ifri, IRIS…) sont rafraîchies à la main, trois fois par semaine, depuis une connexion française.

Sources that block data-center robots (Collège de France, Louvre, Muséum, Ifri, IRIS…) are refreshed by hand, three times a week, from a French connection.

A health check (check_health.py) raises an alert when a critical source drops to zero events.

Le site n’interroge rien en direct : à chaque passage, le scraper écrit les pages, les calendriers et les fichiers de données. Une page événement, une page par organisateur, par discipline, par intervenant, des sélections (« ce soir », « gratuites »…).

The site queries nothing live: on each run the scraper writes the pages, the calendars and the data files. An event page, one page per organiser, discipline and speaker, and selections (“tonight”, “free”…).
