À propos

Un seul endroit pour savoir ce qui se passe dans les amphis parisiens.

Le projet

Les conférences, séminaires et colloques parisiens sont éparpillés sur une dizaine de sites institutionnels, chacun avec son propre agenda, sa propre pagination, son propre format. Beaucoup sont ouverts à tous — mais encore faut-il savoir qu'ils existent.

Ce site les rassemble en un calendrier unique, filtrable par discipline, institution, date et format, avec une carte, un historique et un flux iCal pour s'abonner depuis son agenda.

Le classement par discipline est automatique (mots-clés) : il peut se tromper. L'événement fait toujours foi sur le site de l'institution — cliquez sur une carte pour y accéder.

La mise à jour

  • Chaque jour vers 6h : récupération automatique de toutes les sources.
  • Chaque semaine : passage complémentaire pour les sources qui bloquent les robots des data-centers (Collège de France, pages thématiques Luma).
  • Les événements passés sont conservés dans l'onglet Historique pendant un an.

La technique

Site statique, sans tracker, sans compte, sans cookie tiers. Les données sont collectées par un scraper Python (exécuté par GitHub Actions), publiées en JSON et affichées par une page unique en JavaScript. Le tout est open source : github.com/kovarci/zzzz.

  • Flux iCal global : data/calendar.ics
  • Flux RSS des immanquables : data/digest.xml
  • Données brutes : data/events.json
